# HappyTails Pet Services Frontend

A React + Vite frontend for a pet-services booking experience covering grooming discovery, service selection, appointment scheduling, booking confirmation, and completion flows.

## Portfolio Highlights

- Multi-step booking workflow built with React Router
- Responsive pet-services interface for grooming and appointment management
- Reusable React components and page-level styling
- Calendar/scheduling interactions and confirmation screens
- Frontend architecture separated into components, pages, assets, and services

## Tech Stack

- React
- Vite
- React Router
- Bootstrap / React Bootstrap
- React Calendar
- ESLint

## Main User Flow

```text
Home
  -> Grooming
  -> Book Appointment
  -> Choose Service
  -> Schedule Appointment
  -> Booking Confirmation
  -> Appointment Confirmed
```

## Local Setup

```bash
npm install
npm run dev
```
